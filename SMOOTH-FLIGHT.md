# Плавный лёгкий пролёт

Промежуточный вид больше не останавливается: один непрерывный трек трансформаций соединяет подъём, общий план, подлёт и спуск. Наклон изображения меняется по ходу маршрута, кадры перекрываются по прозрачности. Возврат устроен симметрично. Это имитация камеры на изображениях, без загрузки 3D-движка, модели или видео.

Все используемые растровые изображения перекодированы в WebP с сохранением альфа-канала облаков. Суммарный объём: 28 362 356 → 3 221 446 байт (−89%). Это размер всех изображений сайта, а не обещание конкретного времени загрузки. Полноразмерные PNG сохранены в `previous-assets/png-performance/`, в публикацию они не входят. Подробности размеров — `image-optimization.json`.

Изображение категории начинает подгружаться при наведении или фокусе на её точке. Повторные открытия используют кэш изображения. Браузерные трансформации выполняются через Web Animations API; используются transform/opacity без тяжёлых фильтров движения.

Проверки: шесть тестов маршрутов, отмены, центрирования цели и непрерывного трека; проверка существования всех ссылок на локальные изображения. Визуальная проверка браузером недоступна в этой сессии.
