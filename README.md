# ХАРАКТЕР — жить по-своему

Русскоязычный авторский сайт-концепт жилого комплекса. Вымышленный проект для портфолио. Архитектура, планировки и расположение иллюстративные.

Откройте `dist/index.html` либо обслуживайте `dist` статическим HTTP-сервером. Сборка и установка зависимостей не нужны. Google Fonts загружаются по сети, системные шрифты используются при отсутствии подключения.

## Взаимодействия

- Дневной и вечерний архитектурные рендеры.
- Информационные точки на фасаде и исследование деталей с приближением.
- Истории о среде, галерея и просмотр изображений в модальном окне.
- 6 вариантов квартир, фильтры по комнатам и террасе, сортировка по площади.
- Просмотр и скачивание иллюстративной планировки в SVG.
- Интерактивная схема окружения.
- Демонстрационное приглашение в календарь .ics с временем Екатеринбурга (UTC+5), без отправки данных.
- Адаптивная навигация, управление с клавиатуры, reduced-motion и анимации появления.

`dist/index.html` — тексты и структура. `dist/style.css` — оформление. `dist/app.js` — взаимодействия и данные квартир. `dist/assets` — логотип и созданные встроенным ImageGen изображения. Сведения о промптах: `IMAGE-PROMPTS.md`.

Текущая редакция использует реалистичные прямоугольные башни: dist/assets/character-*-real.png. Предыдущие варианты сохранены в previous-assets. Новые промпты: REALISTIC-IMAGE-PROMPTS.md. Декоративные диагональные значки у ссылок удалены.
